# Edge of the Earth seals

Seal A–E SVG paths are extracted from the ArkhamCards AppIcon set in https://github.com/zzorba/ArkhamCards/blob/master/assets/icomoon/project.json (retrieved 2026-10-17). The app maps A–E to codepoints E908, E907, E906, E905, E904; the campaign text font uses c–g. Original path coordinates and widths are retained, with a gold fill for the BGB page.
