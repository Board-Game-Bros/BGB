# Scarlet Keys map assets

- `map.svg` and `paper.jpeg`: ArkhamCards, commit `5d805697d5c7359fc6baffa3be90d1158ef7f33d`, [assets](https://github.com/zzorba/ArkhamCards/tree/5d805697d5c7359fc6baffa3be90d1158ef7f33d/assets). Original geometry and routes are retained. Browser interactions are implemented separately in `scripts/arkham-journey.js`.
- `assets/data/arkham_tsk_world_map.json`: public location coordinates and geographic labels from [arkham-cards-data campaign.json](https://github.com/zzorba/arkham-cards-data/blob/8b283b08e290d982ee83ec03960e0c4a1e293587/campaigns/tskc/campaign.json). Hidden location, dossier text, scenario outcomes and unrevealed scenario names are omitted. Map locations alone do not imply visits or unlocked access.
- `eye_of_ravens.jpg`: [ArkhamDB card 09519a](https://arkhamdb.com/card/09519a), downloaded from `https://arkhamdb.com/bundles/cards/09519a.png` (the response is JPEG). Displays the stable side, not a claim about current shift state.

Arkham Horror: The Card Game artwork and game content belong to Fantasy Flight Games. These files support this unofficial campaign journal. ArkhamCards and its data contributors are credited on the map.
